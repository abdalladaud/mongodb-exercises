# MongoDB Practice Queries

## Overview

This project practices MongoDB `find()` queries using a student collection.

## Technologies

- MongoDB
- MongoDB Compass

## Queries Practiced

1. Find students older than 22
2. Find students enrolled in React
3. Find names starting with `S`
4. Find students aged 18 or 21
5. Find students who are not using Gmail
6. Find students enrolled in React and older than 20
7. Find students enrolled in React or Node.js
8. Use `$regex` to search names and `.edu` emails

## Schema-less MongoDB

MongoDB is schema-less because documents in the same collection can have different fields and structures.

For example, one student can have `phone`, while another can have `address` or `skills`.

## Files

- `students.js` — student data and MongoDB queries
- `README.md` — project description
